# Crop Ecology (CSP316) Course Portal

A responsive, static portal prototype organized around the supplied CSP316 course outline and Plant Interference teaching note.

## What is included

- Student dashboard and course navigation
- Ten course modules matching the supplied outline
- Detailed Plant Interference lesson based on the supplied teaching note
- Three class-work prompts
- Ten-question knowledge check with feedback and explanations
- Progress tracking stored in the current browser

The other nine topics are outline entries only because lecture notes were not included for them. This prototype does not yet include student accounts, a shared database, lecturer tools, or LMS integrations. Browser progress stays on the device and is not shared with a lecturer.

## Deploy

The project is a plain static site with index.html at the repository root. Connect the repository to Vercel and use the Other framework preset with no build command and . as the output directory.
